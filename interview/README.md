## 维护规则（Agent 执行）

1. 从面经中拆出可独立成题的问题 → 按 `NNN-short-slug.md` 新建文件 → 用 `templates/question.md` 填写 → 在上表登记并互链关联知识点。
2. 题目解答必须落到「能复述给别人听」的程度：一句话答案 + 详细解答 + 代码验证（如适用）+ 追问链。
3. 已有关联知识点时，真题与知识点**双向互链**（真题页链到知识点，知识点 §高频问答 提及该真题）。
4. 面经原文先整体摘录进 `experiences/`（标注来源与日期），再逐步拆题落盘；未拆完的题目留在面经文件的「待拆解清单」。
